# Licensing

Lory is source-available under the [Business Source License 1.1](LICENSE)
(BSL), with an additional use grant, the same as Magpie's and Myna's. This
page says what that means in plain words; where the two differ, the
license decides.

## Free, for everyone

- Reading, changing and sharing the code.
- Development, testing, evaluation, continuous integration, staging and
  demos, on any number of machines.
- **Non-commercial use in production, without limit**: an individual's
  study, research, hobby projects and games, and charities, schools,
  public research and government.
- **Commercial use in production on one machine per application**: the
  data an application's charts and scenes are drawn from is stored on,
  and served from, one machine. Every browser, phone and headset that
  shows the application's pages is free, however many there are.

## Needs a commercial license

- A company's production use of one application whose data is stored on
  or served from **more than one machine**.
- Offering Lory, or a product whose main value is Lory, to others as a
  **hosted or managed service**.

## Counting machines

A machine is one physical computer or one virtual machine, with every
process and container on it.

| A second machine (needs a license) | Not a second machine (free) |
|---|---|
| Another server serving the same application's pages or data | The browsers, phones and headsets that show the pages, Lory running inside them |
| One application's data split across servers | Any program reaching the application over HTTP |
| | Backups of the data at rest |
| | Restoring onto a replacement machine after a failure |

## Forks

A modified copy stays under the same license, whoever modified it and
whatever was added: it may not be used in production beyond these terms,
nor offered as a hosted service, and it may not use the name Lory.

## Four years on

Each version of Lory becomes available under the Apache License 2.0 four
years after it is published: the BSL's change date.
